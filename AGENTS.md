# Learn You a Bend project notes

- This repository builds Learn You a Bend, an interactive Bend 2 tutorial. Do not assume Bend 1 or HVM syntax and tooling apply.
- Use `bend guide` from the development shell for current syntax and standard-library documentation.
- Keep chapter programs small and runnable with `bend src/path/to/file.bend`.
- Use `just build`, `just open`, `just serve`, `just test`, and `just check` for the tutorial workflow.
- Bend is evolving quickly; check compiler output rather than assuming a feature or library API exists.
